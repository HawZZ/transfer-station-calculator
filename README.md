# 中转站计算器

一个无需后端的静态页面，用于将中转站充值条件换算为真实的 `M Tokens / $` 成本。

## 公式

- 可用 M Tokens = 充值等效美元 / 计算倍率 / 5
- 充值折算美元 = 充值金额(CNY) / USD-CNY 汇率
- 真实 M Tokens / $ = 可用 M Tokens / 充值折算美元

模型单价固定为 `gpt-5.6-sol` 的 `$5 / M Tokens`。汇率默认使用表格中的 `6.74`，页面加载和手动刷新时会尝试从 Frankfurter 获取最新 USD/CNY 汇率。

## 记录规则

- 计算记录保存在浏览器的 `localStorage`，刷新页面后仍会保留。
- 官网链接可不填。填写后，页面会尝试从浏览器访问该地址。
- 可访问的官网链接标记为有效。跨域站点无法读取 HTTP 状态时，页面会将可完成网络访问的结果标记为可达。
- 相同的规范化官网链接只保留一条记录，后一次计算覆盖先前记录。

## 本地运行

```bash
npx http-server -c-1 -p 4173
```

打开 `http://127.0.0.1:4173`。

## GitHub Pages

仓库已经包含 GitHub Pages 工作流。将本目录推送到 GitHub 仓库的 `main` 分支后，在仓库的 `Settings > Pages` 中把发布来源设为 `GitHub Actions`。每次推送到 `main` 会重新部署静态页面。
